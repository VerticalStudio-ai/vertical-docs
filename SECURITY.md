# Security policy

## Supported versions

The latest version of `vertical-docs` on npm gets security fixes.

## Report a vulnerability

Do not open a public issue for a vulnerability. Report it privately on GitHub: open the [Security tab](https://github.com/VerticalStudio-ai/vertical-docs/security) of the repository and choose "Report a vulnerability".

Say what is affected, how to reproduce it and what an attacker gains. We aim to answer within five working days. A fix is released as a new version, and the report is credited to you unless you ask otherwise.

## Scope

In scope: the `vertical-docs` package, the Worker it deploys, and the workflows that `vertical-docs init` writes. A docs site that a product builds with Vertical Docs is run by that product: report a problem with such a site's content or hosting to its owner.
