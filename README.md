# docs-kit

A super-light, agent-native docs system: Markdown in a repo, a static site, one search index shared by humans and agents, and an agent that keeps the docs in sync with the code.

Status: phases 0 to 3a of the plan are built: the site with its sidebar, themes and sample pages, the search in the site and in the terminal, the files for agents, images, a content folder outside the project, and `pnpm check`. Hosting and the MCP server are next.
