## Keep the docs in step with the code

The docs of this repository are the Markdown pages in `<folder>/content/`. When a change to the code changes behaviour that a page describes, edit that page in the same change.

- Follow the writing rules, `WRITING.md` of the `vertical-docs` package: `<run> vertical-docs rules` prints them.
- Run `<run> vertical-docs check <folder>` before you say the docs are done.
